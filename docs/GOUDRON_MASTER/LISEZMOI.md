# GOUDRON_MASTER

Dossier de référence du projet GOUDRON (documents de conception). **Ce dossier ne contient pas le code du jeu** : le jeu est `index.html` à la racine du dépôt.

- 02_BIBLE_GAMEPLAY : bible, règles des compétitions, calendrier, cahier « Career Manager » (15/10), briefs du 13/11 (dont le brief de conception consolidé, qui fait référence).
- 03_JOUEURS : fiches visages, noms par région, modèle joueur.
- 04_CLUBS_COMPETITIONS : clubs, districts, académies (JSON).
- 05_TACTIQUE_MATCH : formations, consignes, moteur de match.
- 06_ECONOMIE_CARRIERE : formules et données économiques.
- 07_DECISIONS_CANON : journal des décisions. Reconstruit le 12/11/2026 après la perte du fichier de travail : lire l'avertissement dans le fichier.
- 08_AUDIT : audit v47.

Non inclus : les anciennes versions du jeu (déjà dans l'historique Git ou dans l'archive de l'utilisateur), et les documents du 16 au 21/10 perdus (cahier de la maquette, suivi des tenues, rapport L1). Le dossier final des tenues du District est dans l'archive `GOUDRON_tenues_District_integration.zip` envoyée le 21/10.
