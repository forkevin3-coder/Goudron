# GOUDRON · De la rue au stade

Jeu de gestion de football ivoirien, sur mobile. Joue en ligne :
**https://forkevin3-coder.github.io/goudron/**

Sur iPhone : ouvre le lien dans Safari, puis Partager › « Sur l'écran d'accueil ».
Sur Android : ouvre le lien dans Chrome, puis menu › « Installer l'application ».

La partie est sauvegardée sur l'appareil. Club › « Exporter ma partie » crée une copie de secours.

Projet original : clubs, joueurs, compétitions et montants sont fictifs.
